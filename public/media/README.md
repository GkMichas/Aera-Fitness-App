# AERA media library

Task 9 replaces the original shared training placeholder with named, project-owned media:

- `training/` contains one instructional poster for every curated exercise in the V1 catalog.
- `nutrition/` contains achievable food photography mapped to recipe media IDs.
- `progress/` contains fully clothed synthetic diptychs used only for clearly labeled demo comparisons.

The source PNGs were generated with the built-in ImageGen workflow and the project copies were optimized to JPEG. Exercise components remain ready for short MP4 assets when first-party technique videos are commissioned.
